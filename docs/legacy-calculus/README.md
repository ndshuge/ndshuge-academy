# 🐭 笛卡尔的普林斯顿微积分学院 🐿️

> **由 鼠哥（ndshuge）组织发起，拉里·佩奇 协助开发**

以班纳《普林斯顿微积分读本》为蓝本的交互式微积分学习学院。28 周攻城路线、讲义、即时批改练习、小卷考试、错题集、微积分实验室（可视化交互）一条龙，**打开网页就能学**。

## 🚀 使用链接

👉 **https://ndshuge.github.io/ndshuge-calculus-academy/?v=3**

手机、电脑、平板直接打开就能用。注册一个账号，进度自动云端同步，换设备接着学。

> 💡 若打开后界面不是最新版（浏览器缓存了旧页面），在网址末尾加 `?v=3`（版本号会随更新递增）即可强制加载新版；或分享板块复制链接（自动带版本号）。

## ✨ 功能

- **📜 学习计划**：廿八周攻城路线，七大战役按序攻下
- **🎓 章节课堂**：开讲词 → 知识地图 → 讲义 → 例题 → 易错 → 练习 → 灵魂拷问
- **🏛 练习大厅**：全册精选习题，按章刷题即时批改
- **📝 小卷练习**：每章 15 题小卷，全对通关
- **📕 错题集**：错题自动收集，订正归档，48 小时重做机制
- **🔬 微积分实验室**：ε-δ 极限、导数切线、定积分矩形逼近、单位圆函数，全部可拖动交互
- **🏆 荣誉墙**：称号阶梯 + 徽章墙 + 数学家名人堂
- **🔐 账号系统**：用户名 + 头像注册，找回密码，改用户名/头像/邮箱/密码
- **☁️ 多设备同步**：进度云端保存，登录即合并两端数据（取并集，不丢进度）
- **🏆 学习排行榜**：全班进度实时排名，前三名奖牌
- **💬 给作者留言**：实名留言，建议直接送达作者

## 🛠 技术

- 单文件 HTML（样式脚本全内嵌，零依赖）
- Supabase（Auth + PostgreSQL + RLS 行级安全）
- GitHub Pages 部署
- 内置迷你 LaTeX 渲染，数学公式离线可用
