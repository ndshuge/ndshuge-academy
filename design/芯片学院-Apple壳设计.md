# 芯片战争学院 · Apple 壳改造设计（iOS/Mac 双形态）

> 2026-09-03 · 试点学院：芯片战争（chip.html）。引擎逻辑与内容不动，只换「壳」+ 模块架构 + 动效。
> 目标：手机 = iOS 原生观感（底部 TabBar + 大标题），电脑 = macOS 观感（毛玻璃侧栏 + 内容网格），断点 860px 自动切换。

## 一、模块整理：15 个功能页的收纳架构

现状：15 个页面平铺在侧栏两组里，页与页平级，用户容易迷路。

### 层级设计（三层：Tab → 页内 Hub → 内容）

**第 1 层：四个 Tab（手机底部 / 电脑侧栏主分组）**

| Tab | 用户目标 | 直达页 | 收纳的模块 |
|---|---|---|---|
| 📚 学习 | 学新东西 | 主页（Hub） | 学习计划 · 章节课堂（讲义） |
| 🎯 修炼 | 练和测 | 练习大厅 | 小卷练习（大厅页内已有卷子入口） |
| 📊 收成 | 复盘 | 错题集 | 已订正 · 荣誉墙 |
| 👤 我的 | 人/账号 | 管理账号与进度 | 打卡日历 · 排行榜 · 留言 · 问答批改 · 芯片实验室 · 关于作者/导师 |

**第 2 层：主页 = Hub（收纳中枢）**
主页不再只是一张欢迎卡，改成「行动中枢」：
- 今日目标 widget（进度环 + 🔥 打卡状态）
- 四大入口卡（讲义 / 大厅 / 小卷 / 错题），带数字 badge
- 收成区（称号 + 徽章 3 枚 + 打卡日历缩略）
- 快捷（实验室 / 问答 / 排行 / 留言 / 管理）

**第 3 层：折叠收纳**
- 侧栏分组可折叠（保留现有 max-height 折叠交互，默认「学习/修炼」展开、「更多」收起）
- 「我的」页做成 **iOS 设置式分组列表**（圆角分组表）：账号 / 学习生活（打卡日历·排行·留言）/ 玩法（问答·实验室·关于作者）
- 页内次级切换器（练习大厅的章切换等）保留，视觉升级为 segmented

### 每页的顶部规格统一
- iOS 移动端：页首大标题（34px 粗）+ 副标题日期
- Mac 桌面：继承页首（现 page-head），白卡内容，圆角 14

## 二、动效规格（Apple 质感，克制）

统一时间曲线：`cubic-bezier(.32,.72,0,1)`（Apple 常用），禁 bounce/旋转/闪烁，单动效 ≤0.45s。

| 场景 | 动效 |
|---|---|
| 页面切换 | 内容区旧页淡出上移 12px → 新页淡入上移 8px，0.28s |
| 侧栏展开/收起 | 文字淡出 → 宽度变化（0.35s 错峰，现有结构升级曲线） |
| 折叠分组 | max-height 0.4s 缓动 + 箭头旋转 180° |
| 卡片 hover（Mac） | translateY(-1px) + 阴影加深，0.2s |
| 卡片按压（触屏） | scale(.98)，0.12s |
| 进度条 | 宽度 0.6s 缓动 + 数值 0.4s 淡换 |
| TabBar 选中 | 选中滑块胶囊位移 0.25s（伪元素 transform） |
| 打卡/徽章点亮 | 放大小弹 0.35s：cubic-bezier(.34,1.56,.64,1)（Apple 弹性收尾，无回弹） |
| 页面首入 | Hub 卡片 stagger 淡入上移，每卡 0.4s + 40ms 间隔 |

## 三、壳规格

**通用**：功能页渲染目标（#page-x）与引擎 JS 全部不动，只改导航壳与皮肤 CSS。

**Mac（≥860px）**
- 顶部 28px 半透明菜单栏（非必须，可省略——浏览器内做假菜单栏略喧宾；用窗口红绿灯点缀即可选）
- 左侧毛玻璃侧栏（280px，backdrop blur + 分组导航带数字 badge + 底部今日目标卡）
- 内容区：白卡网格/圆角 14 内容，背景淡灰 #F5F5F7

**iOS（<860px）**
- 顶部大标题区（页面名 + 日期）
- 底部毛玻璃 TabBar（4 tab，选中胶囊）
- 内容：无侧栏，全宽卡片流
- 保留悬浮 ☰（进深层页返回用——或改「返回上一页」）与 🚪 退出学院

## 四、分步实施

1. **V1 壳**：CSS 皮肤层（断点壳 + 毛玻璃 + 圆角卡片）+ 桌面侧栏重组（分组/折叠/徽标）+ 移动 TabBar 骨架（4 tab 绑定现有页）
2. **V2 Hub**：主页改造成「行动中枢」（今日目标环 + 入口卡 + 收成区）
3. **V3 动效**：页面切换/折叠/进度/徽章点亮微动效
4. **V4 我的页**：iOS 设置式分组列表
5. 验证：桌面浏览器拖宽窄实测双形态 + 手机实测 → 满意后复制壳到其余三院

## 五、不做的事（范围护栏）
- 不改判题/同步/账号/结算逻辑
- 不搬内容
- 不引入外部框架/字体（保持单文件离线）
