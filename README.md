## ✨ 特色

- **📖 交互式学习**：每章讲义 + 练习 + 小卷 + 错题本 + 订正闭环，打开网页就学
- **💻 代码即时判题**：Python（Pyodide）与 C（自举编译器）都在浏览器里真运行，零安装
- **✅ 每日目标绿框**：每天「学一节 + 做一份卷子」，回门户入口卡片变绿，记录你的坚持
- **🔐 四院账号互通**：登录一次，四个学院通；云端进度按学院命名空间隔离，互不覆盖
- **📤 进度自由搬运**：各院侧栏可导出/导入进度，换设备不丢
- **🖥 手机友好**：☰ 菜单呼出导航，🚪 随时退出回门户

## 🛠 技术

- 单文件 HTML（样式脚本全内嵌，零依赖），各学院一个子页，门户统一入口
- 同域 localStorage 进度隔离（前缀 `pjc_`/`pyc_`/`cc_`/`chip_`）+ Supabase 云端同步
- 浏览器内运行时：Pyodide（Python）、自举 c99js（C）
- GitHub Pages 部署，更新即推即生效
